# Security policy

ActionTrace 0.1 is experimental. Its findings require review, and a clean scan is not evidence that a repository is secure.

Security issues in the analyzer include unintended file access, code execution while parsing, unsafe report rendering, and important silent coverage failures. Do not include real secrets, private workflow contents, or customer data in public issues.

After publishing a fork, the maintainer should enable GitHub private vulnerability reporting in repository settings. If that channel is unavailable, open a minimal public issue requesting a private contact without disclosing sensitive details.

Supported release line: 0.1.x, on a best-effort basis. No response-time or maintenance guarantee is implied.
